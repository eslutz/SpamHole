# SpamHole brand

The website uses charcoal `#15171C`, graphite surfaces `#23262F`, warm white `#F5F4F0`, amber `#F2A45A`, and secondary text `#ADB4C2`. Decorative layers behind the illustrative phone are graphite.

The app uses the same amber accent in dark mode, with `#8A470C` in light mode to maintain text contrast. Native system surfaces and semantic error colors remain adaptive.

The website phone is generated illustrative artwork with a synthetic telephone number, not a screenshot of the shipped app. Local phone, gear, and arrow icons are Bootstrap Icons v1.13.1, MIT licensed, copyright The Bootstrap Authors. https://github.com/twbs/icons/blob/v1.13.1/LICENSE
