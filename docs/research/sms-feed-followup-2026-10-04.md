# SMS sender-feed qualification follow-up

Checked October 4, 2026. **No qualifying feed found; public-release gate remains blocked.** This targeted review does not establish that a qualifying source is impossible or absent everywhere. No source was added to the trusted catalog, and no subscription, purchase, account registration or publisher contact was made.

## Qualification standard

The existing [source contract](../sources.md) and [release checklist](../release-checklist.md) require a free/open license for direct on-device use, exact originating SMS identifiers, SMS-specific substantive confirmation and reviewed methods, dated coverage, expiry/review dates, corrections/withdrawals, source lineage and an adjudicated acceptance set. Public accessibility, a code license, complaint counts or a message-level phishing label alone do not satisfy that contract. Local SMS rules remain available. Incoming message bodies must not be analyzed or sent to a service.

## Concrete next action

Prioritize **Smishtank publisher qualification**, rather than building an unapproved adapter: obtain a current direct HTTPS bulk endpoint, explicit free/open dataset grant covering local normalization/derivation and any necessary redistribution, sample exact originating identifiers with country/context and stable records, documented review/expiry/withdrawal semantics, and evidence separating OCR labels/spoofed legitimate IDs from substantiated spam senders. Publisher contact requires separate authorization; this task did not send a message.

Only after every contractual gap is resolved should a maintainer qualify the source, add a reviewed catalog entry and run an adjudicated, time-separated sender acceptance set with precision/recall, legitimate-message false positives, sample size and correction-to-install latency. Preserve the existing zero false-Junk requirement in the designated legitimate test set, without claiming zero real-world error. Until then, **hold public release**; device profiling and accessibility work can continue independently.
